THE MAKERS — GITHUB PAGES SITE

WHAT THIS IS
A standalone static website for The Makers fantasy football league. It does not touch the Miscellaneous Expenditures site.

HOW TO PUBLISH WITH THE SAME GITHUB ACCOUNT
1. In GitHub, click New repository.
2. Name it something like: the-makers
3. Make it Public.
4. Create the repository.
5. Upload ALL FILES AND FOLDERS INSIDE this folder to the ROOT of the new repository. Do not upload the ZIP itself.
6. Commit the upload.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Branch: main. Folder: / (root). Save.
10. The default project URL will be similar to: https://miscexpffl.github.io/the-makers/

IMPORTANT
- There is intentionally no CNAME file in this package because this is a separate project-site build and no custom domain has been assigned yet.
- Your existing MiscExp repository/domain is untouched.
- All links are relative, so this site works correctly from a GitHub project URL.
