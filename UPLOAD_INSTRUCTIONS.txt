HOW TO UPLOAD
1. Open https://github.com/TheMakersFFL/the-makers
2. Stay on the main branch.
3. Choose Add file > Upload files.
4. Drag ALL files from this folder into the repository root.
5. GitHub will show some files as replacements and some as new files. That is expected.
6. Commit directly to main with a message such as:
   "Publish Makers Week 1 Tuesday update"
7. Wait for GitHub Pages to finish deploying.
8. Open https://themakersffl.github.io/the-makers/index.html and hard-refresh once if the old site is cached.
